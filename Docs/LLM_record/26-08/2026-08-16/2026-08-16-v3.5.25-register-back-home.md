# 2026-08-16 V3.5.25 注册页新增返回首页入口

- **日期与时间**：2026-08-16 11:30
- **任务等级**：L2（功能新增：1 组件 + 1 locale 文件，无新文件）
- **触发来源**：用户指示 —— Register 组件缺少返回根目录（首页 LandingView）的功能

---

## 一、问题分析

### 核心症状

登录/注册页（`/register`）只能通过浏览器后退返回首页，页面内没有任何返回 LandingView（根路径 `/`）的入口。

### 根本原因

`RegisterView.vue` 的头部（`brand-row`）只有品牌徽标 + 标题 + 语言切换器，缺少导航出口；`LandingView` 的「登录 / 注册」按钮（`router-link to="/register"`）是单向的，无对应回程链接。

### 受影响模块

- 注册页头部导航（`RegisterView.vue`）
- 首屏文案（`locales/core.js` landing 段，根路径与注册页均为首屏，键必须进 core 避免懒加载缺口）

### 候选方案对比

| 方案 | 说明 | 评价 |
|---|---|---|
| A. 品牌徽标/标题整块可点 | 点 logo 回首页（常见惯例） | ✗ 无文字提示，可发现性差，用户明确要求「功能」而非隐藏手势 |
| B. 头部新增独立返回按钮 | `router-link to="/"` pill 按钮：图标 + 「返回首页/Home」文案，样式与语言切换器同风格 | ✓ 显式可见、双语、窄屏收敛为图标（aria-label 兜底） |

**选定方案 B**（放置于 brand-row 最左侧，符合「返回在左」的导航惯例）。

---

## 二、修改内容

1. `frontend/src/app/RegisterView.vue`
   - 模板：品牌区（`.brand-badge` + `.brand-text`）整体包裹为 `router-link to="/"`（class `brand-link`，`:title` + `:aria-label` 走 `landing.backHome`）。
   - 脚本：lucide 导入新增 `Home`（项目内 `CesiumToolPanel.vue` 已有同款导入先例）。
   - 样式：新增 `.brand-link`（flex 布局与原 brand-row 同构，hover 轻微降透明度提示可点 + focus-visible 焦点环）；≤768px 媒体查询内同步收紧间距。
2. `frontend/src/locales/core.js`
   - landing 段双语各新增 `backHome`：zh `'返回首页'` / en `'Home'`（core 即首屏权威键源，`navLogin` 同款先例；完整 chunk 的 deepMerge 不会覆盖）。

### 设计迭代（用户反馈后调整，同任务内）

- **V1（独立 pill 按钮，已废弃）**：`brand-row` 左侧新增「Home 图标 + 返回首页/Home 文案」的独立 pill 按钮 —— 用户反馈「很难看，logo 被挤到一边」。
- **V2（品牌区可点，已废弃）**：删除独立按钮与 `Home` 图标导入，品牌区（logo + 标题）整体变为返回首页链接，零额外占位 —— 可发现性弱（仅 hover 降透明度 + title 提示），用户要求「轻松辨识」。
- **V3（现行最终方案）**：右侧操作区方案——语言切换器**左侧**新增 34px 圆形房子图标按钮（`back-home-icon`，`router-link to="/"`），样式与 `.lang-toggle` 同款半透明白 pill（hover 提亮 + focus-visible 焦点环）；logo 及品牌区保持左上原样（品牌区可点保留为隐藏强化入口，零视觉成本）；`landing.backHome` 键同时供 icon 与 brand-link 的 title/aria-label 消费。

## 三、修改原因

补齐 LandingView ↔ RegisterView 的双向往返导航闭环，用户在登录/注册页可一键回首页浏览产品介绍；i18n 键进 core.js 保证注册页首屏即命中，不依赖懒加载 chunk。

## 四、影响范围

- 注册页头部导航（登录/注册/邮箱绑定/密码重置各模式均可见，位于 form-header 外层）
- `locales/core.js` landing 段（双语键，仅新增，无破坏）
